# Four-minute demonstration: one complete resident story

Use the judge package and `docs/JUDGE-START-HERE.md` to reproduce this without an account, card or API key. Use synthetic questions only. The hosted version can use Gemini 3.1 Flash-Lite; distinguish real model responses from the clearly labeled directory fallback.

**0:00–0:25 — The problem.** “A Mableton mailing address does not tell you which organization handles every service. MabletonLink helps find the right provider and next step. It is an independent prototype and does not submit requests.” Show readable English Home, search and Language / Idioma.

**0:25–1:20 — Missed pickup.** Choose Trash pickup → My regular pickup was missed → I am not sure. Explain: the actual collector is the contracted private hauler or HOA provider. The city approves companies but does not collect trash. Check the bill/container label/property manager to identify the company. The approved list is not an address-to-hauler lookup. Open the sources disclosure; do not send a report or invent a company.

**1:20–2:00 — Same story, Spanish.** Switch to Español without leaving the result. Read the direct instruction to identify the collection company and the city/provider distinction. Explain that Spanish wording received AI specialist review, while independent human comprehension remains untested. External official pages may be English-only.

**2:00–2:45 — Save and print that same plan.** Choose Guardar este plan → Favoritos → Identifique primero la empresa que recoge su basura. Choose Imprimir o guardar como PDF. Point out official sources and the statement that no request was submitted. “This is a plan, not an agency receipt or a completed collection report.” Do not switch to a different journey before printing.

**2:45–3:20 — Works without AI.** In the standalone copy (no backend/key), ask No recogieron mi basura. Show Orientación del directorio: la IA no está disponible and the trash journey link. Guided choices, Spanish text, saved plans and printing work without model access. Do not imply a fresh visit to the hosted URL works offline.

**3:20–4:00 — Evidence, access and limits.** Show docs/DEADLINE-READINESS.md: separate the live model benchmark, hosted availability checks, 35 backend tests and five AI walkthroughs. Report failed/unrun model cases rather than calling connectivity accuracy. Actual human participants/reviewers remain zero. Present the public link, then the ZIP's tested no-account route as an additional reproduction option. State the Google free-tier quota, not unlimited access.

If live Gemini fails, identify its fallback honestly. Read the current gate/evidence status instead of repeating an old perfect-score claim.
